GitHub Actions Fehler: "must specify exactly one of workload_identity_provider or credentials_json"

Das bedeutet in diesem Projekt fast immer:
- Das Secret FIREBASE_SERVICE_ACCOUNT fehlt
- oder es ist leer
- oder es wurde der falsche Inhalt gespeichert

Richtig ist:
- Secret-Name: FIREBASE_SERVICE_ACCOUNT
- Wert: kompletter Inhalt der Service-Account-JSON-Datei
  kalender-rai-firebase-adminsdk-....json

Falsch ist:
- nur die E-Mail-Adresse des Service Accounts
- nur die Project ID
- firebase.json als Secret
- der Dateiname statt dem JSON-Inhalt

Pfad in GitHub:
Settings > Secrets and variables > Actions > New repository secret

Danach:
- den fehlgeschlagenen Workflow erneut starten
- oder einen neuen Commit auf main pushen
